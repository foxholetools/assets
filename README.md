# Foxhole Assets

Community-contributed assets extracted from Foxhole game files.

## Contents

This repository will contain:
- Extracted textures (PNG)
- Exported 3D models (GLTF/PSK)
- Audio files (WAV/OGG)
- Asset metadata and documentation

## Usage

This repository is designed to be used as a Git submodule in the main [foxhole-game](https://github.com/foxholetools/foxhole-game) extractor project.
